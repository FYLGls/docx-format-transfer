# 确认 UX 剧本（让用户改得省力）

设计目标：用户说"按模板改格式"后，全程只需要**看清单、回短句**，不需要学任何术语。

## 流程总览
```
提取模板 → 展示清单（分级置信度）→ 用户确认（三式任选）→ 提取目标+歧义确认 → dry-run → 执行 → 报告
```

## 1. 清单展示（report.md 投影为对话消息）
- 按维度分组的人类可读表格：`序号 | 项目 | 模板规则 | 置信度与证据 | 默认动作`
- 置信度只对用户说三档人话：**已确认**（high，绿色✅）/ **基本确定**（medium，⚠️）/ **需要你拍板**（low，❓）。
- 证据说人话："12 张图里 11 张宽 14cm → 按统一 14cm 处理，1 张 10.5cm 的离群已忽略"。
- 消息末尾给默认推荐："直接回复『按推荐来』，我只会再问你 ❓ 的 3 项"。

## 2. 三级确认方式（任选，可混用）
| 方式 | 用户输入样例 | 处理 |
|------|-------------|------|
| 快速 | "按推荐来" / "高置信的直接做，低的问我" | 仅逐项询问 low 项 |
| 逐项口语 | "7 改成黑体三号；12 题注分隔符用全角空格；15 不要每章另起页" | 模型解析成 JSON patch 写回 confirmed profile，回复复述确认 |
| 文件 | （用户编辑 checklist.md 后）"按文件里的来" | 读回文件与档案 diff，列出与上次差异再执行 |

## 3. 模糊项提问规范
- **只出选择题，不出开放题**：每问 ≤4 选项 + 推荐 + "其他"兜底。
- 一次最多问 3-4 问，多了分批；带上下文引用："模板里 9/10 的图注是『图3-1 标题』半角空格，1 个没有空格——按有空格处理？"
- 目标文档歧义（元素映射）单独一轮：列出疑似标题/题注段落的前 20 字 + 行号，用户回复"第3、5、8段是一级标题"这类短句即可。

## 4. Dry-run（动笔前最后一道闸）
- 输出摘要："共将修改 87 处：页面 5 · 样式 12 · 题注 34 · 表格 8 · 图片 12 · …"，附 low 项明细。
- 用户回"可以"/"先不要 XX"后才执行。
- 明确承诺：**不改你的原文件，结果存为新文件**；内容文字除编号/题注外零改动。

## 5. 交付报告
- changes.md：每类改了什么、跳过了什么及原因（如"模板无公式 → 公式未动"）。
- verify 报告：✅ 通过项 / ⚠️ 容差内偏差 / ❌ 未达标项及原因。
- 提醒事项只说必要的：在 Word/WPS 里按 Ctrl+A → F9 刷新域（目录页码）。
- 若模板本身有 flag（不一致），报告里重述异常供用户回头修模板。

## 6. 异常路径
- 文档加密/受保护 → 停止并告知，不猜密码。
- .doc 老格式 → 提示先另存为 .docx（或经 LibreOffice 转换后再处理）。
- 模板某维度缺失 → 该类不修改并明说，不拿默认值硬套。
- 超大文档（>150 页）→ 预告耗时，分节处理。
