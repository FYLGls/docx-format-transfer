# 应用顺序手册（五阶段 + 收尾）

核心原则：**容器→定义→内容→分页→域**。凡是会改变内容高度的操作（字体、行距、图片尺寸）必须发生在分页处理之前；分页类操作放在最后、自上而下单遍执行，用渲染器的真实分页结果判定，避免"改一处、处处变"的震荡。

## 阶段 0：预处理
1. 复制目标文档为工作副本（原件永不改动，输出写新文件）。
2. 加载 confirmed profile + element_map（含用户确认过的标题级别映射）。
3. 幂等基线：若目标已有部分符合 profile 的属性，重设同值不算修改（保证可重跑）。

## 阶段 1：容器（节/页/页眉页脚）
1. 分节结构对齐模板角色（cover→front_matter→body）：只在角色边界不同处增删分节符，不移动内容。
2. 逐节写 `pgSz`/`pgMar`/`pgNumType`；页码域 instrText 同步写格式开关（WPS 兼容）。
3. 迁移页眉页脚（内容+rPr+分隔线），设置 `titlePg`/`evenAndOddHeaders`。
4. 分栏 `w:cols`。

## 阶段 2：样式定义层
1. 覆写 styles.xml：Heading1-3、正文、题注（Caption）、超链接等样式定义（字体三槽/字号/加粗/行距/段距/对齐/缩进）。
2. 迁移/重建 numbering.xml 多级编号定义（模板是自动编号时）。
3. 此阶段不改任何段落实例——让样式层先定型，实例清理在阶段 3。

## 阶段 3：内容元素级（自上而下单遍扫描）
按文档顺序处理，每类元素用 element_map 索引：
1. **标题**：套用对应 Heading 样式；手打编号方案 → 正则重写编号文本（`第X章`/`X.Y`）；清标题段的正文直接格式。
2. **正文段**：清除与样式冲突的直接格式（rFonts/sz/spacing/ind），保留加粗斜体等行内强调。
3. **题注**：
   - 解析旧题注（正则捕获 label/num/sep/title）；
   - 按档案重建文本：域方案 → 注入 `STYLEREF n \s`+`SEQ`域并**预写字面结果**（打开即可见正确编号，F9 后不变）；手打方案 → 维护章节计数器重排全文档；
   - 位置错误（图注在图上）→ 移动题注段；
   - 交叉引用同步更新字面值。
4. **参考文献/列表**：编号格式统一（`[n]`）、悬挂缩进、字号；**不动字段内容**。
5. **表格**：三线表边框重设（表级 top/bottom + 表头行下边框，清竖线/内横线）、表头行格式、tblHeader、cantSplit（行级，此处只写属性不做分页决策）、表宽、单元格字体。
6. **图片**：按宽度规则等比缩放（改 `wp:extent` 及内部 `a:ext`，保持纵横比）、对齐。
7. **公式**：OMML 字体字号覆写；编号段落制表位（居中+右对齐）。
8. **代码块**：按 box_style 装框（single-cell-table 优先：包裹段落为单格表+边框+底纹；paragraph-border：逐段 pBdr+shd）、等宽字体、单倍行距。

## 阶段 4：分页布局（最后做）
前置条件：阶段 1-3 完成，内容高度已定型。
1. 自上而下单遍：
   - 图段落与题注段 keepNext/keepLines 绑定（图注在下：图段 keepNext；表题在上：表题段 keepNext）；
   - 章标题 pageBreakBefore / keepNext（按档案）。
2. **渲染评估**（LibreOffice headless 转 PDF → pdftoppm/文本层，或无渲染器时按行数估算降级）：
   - 找跨页表、孤立题注（题注与对象分处两页）；
   - 短表（≤模板行高×N 且能整页容纳）→ 全行 cantSplit+末行前段落 keepNext 实现"整表不分页"；
   - 长表 → tblHeader 重复表头（续表惯例的等价实现，报告中明示）；
   - 孤立题注 → 对应 keep 绑定补强。
3. 复渲染复查，至多 2 轮（防 keepNext 连锁导致的死循环，超限记 flag 交用户）。

## 阶段 5：域收尾与验证
1. TOC：注入/更新 TOC 域 + 灰色斜体"右键更新域"提示段。
2. 全文档域字面值刷新（题注/交叉引用/PAGE）。
3. 运行 verify_format.py：重提取输出 → 逐叶子比对 profile（容差 cm±0.05/pt±0.5/倍数±0.05）+ 内容零损坏断言（题注编号与域结果之外的正文字符逐字相等）。
4. 输出 changes.md（分类计数+明细）与 verify 报告。

## 回滚与幂等
- 原件只读；输出文件带时间戳，重跑覆盖的是上次输出。
- 每阶段写日志（改了哪些元素索引），dry-run 模式只产出日志不落盘。
